# SX127x radio configuration

The default configuration is 915 MHz, spreading factor 7, bandwidth 125 kHz,
coding rate 4/5, CRC enabled, an eight-symbol preamble and private sync word 0x12.
The constants are in include/drivers/sx127x/sx127x_config.h.

The radio and module must support the selected band. Semtech lists SX1276 as
137–1020 MHz and SX1278 as 137–525 MHz. The 915 MHz default therefore does not
apply to SX1278. The module's RF matching and antenna also constrain its band.
[Manufacturer specifications](https://www.semtech.com/products/wireless-rf/lora-connect).

SPI register reads clear the address write bit; writes set it. The driver sets
the FIFO pointer, payload length and mode registers and polls IRQ flags.
Receive uses FIFO_RX_CURRENT_ADDR and rejects CRC error frames before reading data.
DIO0 is wired for a future interrupt path but is not used for interrupt-driven RX/TX.

The current driver does not identify every chip variant or validate every module.
There is no RSSI/SNR reporting, LoRaWAN stack, CAD scheduling or low-power state machine.
